# Έξοδα

Ο φάκελος περιέχει τη θεωρία και τις λογιστικές εγγραφές που σχετίζονται με τα έξοδα.

## Κύρια θέματα

- Αμοιβές τρίτων
- Υπηρεσίες
- Λειτουργικά έξοδα
- ΦΠΑ εισροών
- Παρακράτηση φόρου

## Κανόνας

Όταν μία συναλλαγή περιλαμβάνει έξοδο, ΦΠΑ ή παρακράτηση φόρου, πρέπει να εξετάζονται μαζί οι σχετικές ενότητες.

Οι υπολογισμοί πρέπει να εμφανίζονται πριν από τη λογιστική εγγραφή.
