# Έσοδα

Ο φάκελος περιέχει τη θεωρία και τις λογιστικές εγγραφές που σχετίζονται με έσοδα και πωλήσεις.

## Κύρια θέματα

- Πωλήσεις εμπορευμάτων
- Έσοδα
- ΦΠΑ εκροών
- Πελάτες
- Πωλήσεις με πίστωση
- Είσπραξη απαιτήσεων

## Κανόνας

Σε κάθε πώληση πρέπει να διαχωρίζονται:

- καθαρή αξία,
- ΦΠΑ,
- συνολική απαίτηση από τον πελάτη.

Δεν πρέπει να προστίθεται επιπλέον λογιστική εγγραφή αν δεν ζητείται ή αν δεν υποστηρίζεται από τα δεδομένα της άσκησης και τη θεωρία.
