# Γενικές Ασκήσεις Λογιστικών Εγγραφών

Ο φάκελος περιέχει ασκήσεις που συνδυάζουν πολλές ενότητες της Χρηματοοικονομικής Λογιστικής Ι.

## Κύρια θέματα

- Χρέωση / Πίστωση
- Αγορές
- Πωλήσεις
- ΦΠΑ
- Πελάτες
- Προμηθευτές
- Αξιόγραφα
- Έσοδα
- Έξοδα
- Πάγια
- Υποχρεώσεις
- Απαιτήσεις

## Κανόνας

Σε κάθε ημερολογιακή εγγραφή πρέπει να ισχύει:

**Σύνολο Χρέωσης = Σύνολο Πίστωσης**

Αν δεν ισχύει, η εγγραφή πρέπει να ξαναελεγχθεί.

Οι λυμένες ασκήσεις αυτού του φακέλου χρησιμοποιούνται ως πρότυπο για τη μορφή και τη μεθοδολογία των λύσεων εξέτασης.
