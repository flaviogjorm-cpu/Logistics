# Α΄ Εξάμηνο — ACCFIN102 — Θεμέλια

Η ύλη αυτού του φακέλου αποτελεί τη βάση για τη Χρηματοοικονομική Λογιστική Ι.

## Σκοπός

Η ύλη του Α΄ εξαμήνου χρησιμοποιείται όταν ένα θέμα του Β΄ εξαμήνου απαιτεί βασική λογιστική γνώση ή προαπαιτούμενη μεθοδολογία.

## Κύρια θέματα

- Εισαγωγή στη Λογιστική
- Ισολογισμός
- Λογαριασμοί
- Λογιστικό Σχέδιο ΕΛΠ
- Διπλογραφικό σύστημα
- Λογιστικά βιβλία
- Λογιστικές εγγραφές
- Αποσβέσεις
- Μεταβατικοί λογαριασμοί
- Κατάσταση Αποτελεσμάτων Χρήσης
- Λογιστικό κύκλωμα

## Κανόνας

Το Α΄ εξάμηνο δεν αγνοείται σε θέματα του Β΄ εξαμήνου.

Χρησιμοποιείται ως θεμέλιο για:
- επιλογή σωστών λογαριασμών,
- κατανόηση Χρέωσης / Πίστωσης,
- δομή ημερολογιακής εγγραφής,
- βασικούς λογιστικούς κανόνες.

Αν όμως το Β΄ εξάμηνο δίνει ειδικότερη μέθοδο, υπερισχύει η μέθοδος του Β΄ εξαμήνου.
